A* Search Algorithm Deep Dive

Comprehensive analysis of the A* search formulation for the 8-puzzle problem, heuristic properties, mathematical proofs of admissibility, optimality, and complexity.

Description & Working Principle

A* Search is an informed (heuristic) search algorithm that computes the lowest-cost path from an initial state to a goal state. At each step, it chooses to expand the node $n$ that minimizes the evaluation function:

$$f(n) = g(n) + h(n)$$
  • $g(n)$: The exact cumulative path cost from the start state to node $n$ (number of moves made).
  • $h(n)$: The estimated heuristic cost from node $n$ to the goal state.
  • $f(n)$: The estimated total cost of the cheapest solution passing through node $n$.

Completeness & Optimality

• Completeness: A* is guaranteed to find a solution if one exists, provided the branching factor $b$ is finite and step costs $c \ge \epsilon > 0$.
• Optimality: A* is guaranteed to return the optimal (shortest) solution path if:
  • In tree search: the heuristic $h(n)$ is admissible (never overestimates the true remaining cost, $h(n) \le h^*(n)$).
  • In graph search: the heuristic $h(n)$ is consistent (monotone), satisfying the triangle inequality: $h(n) \le c(n, a, n') + h(n')$.

Comparison of Implemented Heuristics

1. Misplaced Tiles ($h_1$):

Counts tiles that are not in their target coordinates (excluding the blank space). Admissible because each misplaced tile must move at least once. However, it ignores distance, leading to larger frontier sets.

2. Manhattan Distance ($h_2$):

Sum of horizontal and vertical distances of tiles from their target positions. For every state $n$, $h_2(n) \ge h_1(n)$ ($h_2$ strictly dominates $h_1$). Therefore, A* with Manhattan distance explores strictly fewer or equal nodes.

Complexity & Practical Limitations

Time Complexity: O(bd) Exponential in worst case
Space Complexity: O(bd) Must retain all nodes in memory

Limitation: Because A* maintains both the Frontier (Open List) and Explored Set (Closed List) in memory to guarantee optimality and avoid redundant cycles, memory exhaustion is typically the primary constraint for very deep puzzle states.

Mathematical Solvability (Inversion Parity Theorem)

An 8-Puzzle consists of 9 tiles (numbers 1 to 8 and one blank space). The total number of board permutations is $9! = 362,880$. However, the state space is split into exactly two disjoint, disconnected subgraphs of $181,440$ states each.

A state $S$ is reachable from a goal state $G$ if and only if:

$$\text{Inversions}(S) \equiv \text{Inversions}(G) \pmod 2$$

Horizontal moves change zero tile inversions. Vertical moves swap the blank with a tile 3 positions away, which changes the inversion count by $+2, 0,$ or $-2$, preserving the odd/even parity invariant.
